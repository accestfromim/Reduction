安全说明

1. 这是个人使用的未签名 Windows 程序，不是商业软件。
2. 程序默认不开放任意命令执行；必须显式 -allow-exec 才启用。
3. 程序只监听局域网，请勿做公网端口映射。
4. Token 等同于电脑操作权限，泄露后请删除 pc-agent-config.json 重新生成。
5. 如果 Defender 报毒：
   - 先核对 SHA256。
   - 不要关闭 Defender 或添加排除目录。
   - 提交误报：https://www.microsoft.com/en-us/wdsi/filesubmission
   - 仍不放心就停止使用本 exe，改用 Windows OpenSSH + Tailscale。

当前发布包中的 exe：
DSAssistAgent.exe
SHA256 见上级目录的 SHA256SUMS.txt 或压缩包内的 SHA256.txt。
